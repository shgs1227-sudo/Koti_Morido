まず、全体の分岐をつかむ

同じ「盛土等」でも、場所、工事の内容、規模、既存の許可によって入口が変わります。

1. 許可・届出を判定する

原資料の要否判定フロー（印刷9ページ）を、確認する順番に並べ替えています。

  1. 所在地と区域を確認高知市か、それ以外か。宅地造成等工事規制区域・特定盛土等規制区域のどちらかを区域図で確認します。
  2. 対象外・不要工事を確認公共施設用地や災害のおそれがないと認められる工事等は、原資料3.4の条件を確認します。通常の営農行為も内容・規模により扱いが分かれます。
  3. 工事の種類と一体性を確認宅地造成・特定盛土等か、一定期間後に除却する土石の堆積か。複数工事の一体性がある場合は一体の規模で判定します。
  4. 許可・届出の規模を照合下の表に当てはめます。特定盛土等規制区域では、許可規模に満たなくても届出規模に該当する場合があります。
  5. みなし許可と他法令を確認都市計画法の開発許可や国・県・中核市の協議により、盛土規制法の許可を受けたものとみなす場合があります。農地法・森林法などの別手続きも確認します。
原資料：印刷9ページ（PDF 13ページ）、印刷21～23ページ

2. 許可申請の二つの流れ

申請前の準備と審査までは共通し、工事中と完了時に違いがあります。

許可 ①

宅地造成・特定盛土等

  1. 事前相談許可の要否、計画、手数料算定面積を相談。
  2. 周辺住民への周知・土地所有者等の同意申請前に実施し、証明資料を準備。
  3. 許可申請書を提出県が受理し、特定工程を確認して審査。
  4. 許可証交付・許可情報公表許可を受けた後、標識を掲示して着手。
  5. 施工中の手続き対象規模なら3か月ごとに定期報告。特定工程を含む場合は中間検査を申請し、合格証を得て次工程へ。
  6. 完了検査を申請工事完了後4日以内に申請。適合すれば検査済証交付。
原資料：印刷24ページ（PDF 28ページ）
許可 ②

土石の堆積

  1. 事前相談規模、堆積計画、安全措置、手数料算定面積を相談。
  2. 周辺住民への周知・土地所有者等の同意申請前に実施し、証明資料を準備。
  3. 許可申請書を提出県が審査し、許可証を交付。許可情報を公表。
  4. 標識掲示・工事着手対象規模なら3か月ごとに定期報告。土石の堆積は中間検査の対象外。
  5. 土石を全て除却工事完了後4日以内に確認申請。県が除却を確認し、確認済証を交付。
原資料：印刷25ページ（PDF 29ページ）

申請前にそろえる主なもの

周知の記録、土地所有者等の同意書、位置図・地形図・平面図・断面図、設計・構造計算書、現況写真、工事主の資力・信用と工事施行者の能力を示す資料、他法令の許認可状況です。宅地造成・特定盛土等は省令様式第2、土石の堆積は省令様式第4を使用し、原資料では正副2部を求めています。必要な添付書類は工事内容によって異なります。

住民周知の方法は説明会、書面配布、現地掲示とインターネット閲覧のいずれかです。原資料に示された渓流等の土地で高さ15m超の盛土を行う場合は説明会が必須です。

原資料：印刷26～38ページ（PDF 30～42ページ）

審査期間の目安

原資料の標準処理期間は、宅地造成・特定盛土等の許可が30日、土石の堆積の許可が14日です。適正な申請を前提とし、補正に要する期間などは含まれません。

原資料：印刷43ページ（PDF 47ページ）

3. 特定盛土等規制区域の通常届出

許可対象未満でも届出対象規模に達する工事は、着手30日前までに計画を届け出ます。

届出

特定盛土等・土石の堆積の届出

  1. 事前相談区域、規模、必要書類を確認。
  2. 着手30日前までに届出書を提出県が受理。原資料では手数料不要。
  3. 届出情報の公表県がホームページに工事情報を公表。
  4. 標識を掲示して工事着手標識は工事完了日まで掲示。
  5. 工事完了後、速やかに完了届と写真を提出県が完了届を受理。

届出書は、特定盛土等が省令様式第19、土石の堆積が省令様式第20。原資料では各1部で、位置図、地形図、平面図、写真などを添付します。

原資料：印刷57～64ページ（PDF 61～68ページ）

4. みなし許可・協議

協議

国・県・中核市が行う工事

  1. 許可対象規模に該当するか判定規制区域内の宅地造成・特定盛土等・土石の堆積が対象。
  2. 高知県へ協議を申し出る宅地造成・特定盛土等は細則第5号様式、土石の堆積は細則第6号様式。必要書類・図面を添付。
  3. 協議成立で許可を受けたものとみなす工事中の標識、対象となる定期報告・中間検査、完了検査などは適用。
  4. 計画変更時は変更協議軽微な変更等を除き、細則第8号・第9号様式と変更資料を提出。
原資料：印刷16～20ページ（PDF 20～24ページ）
みなし許可

都市計画法の開発許可を受けた工事

  1. 開発許可と盛土規制法の対象規模を確認両方に該当すると、盛土規制法の許可を受けたものとみなす。
  2. 都市計画法に従い許可・変更・完了の手続きを進める盛土規制法の許可・届出を別に行う必要はない、と原資料は説明。
  3. 盛土規制法の施工中義務を実施標識掲示、対象となる定期報告・中間検査は必要。
  4. 都市計画法の完了検査で終える都市計画法第36条の検査済証を、盛土規制法の検査済証交付とみなす。

原資料には、令和7年4月1日の区域指定前に開発許可を受け、指定日以降に工事着手する場合は「みなし許可」にならず、盛土規制法の許可が必要と記載されています。

原資料：印刷20ページ（PDF 24ページ）、印刷52ページ

5. 許可後の手続き

許可後は、着手時の標識から変更、施工中の報告・検査、完了まで手続きが続きます。

変更

計画を変更するとき

変更許可申請

許可を受けた計画を変更する場合、軽微な変更を除いて変更許可を受けます。宅地造成・特定盛土等は省令様式第7、土石の堆積は省令様式第8と変更内容の資料を提出します（原資料では正副2部、手数料あり）。

軽微な変更の届出

工事主・設計者・工事施行者の氏名・名称・住所、着手予定日・完了予定日の変更は、速やかに細則第7号様式で届け出ます。土石の堆積で工事予定期間が従前を超える変更は、原資料では変更許可の対象です。

原資料は、計画の同一性を失わず災害防止に支障がない些細な変更は変更許可申請を要しないとしています。判断に迷う場合は事前相談を利用してください。

原資料：印刷45～46ページ（PDF 49～50ページ）
廃止

許可工事を廃止するとき

許可対象規模未満の状態で廃止する場合は、細則第11号様式の工事廃止届と現況写真を1部提出します。許可対象規模を超えている場合は、原資料では変更許可申請と災害防止措置を行い、工事を完了させる流れです。

原資料：印刷47ページ（PDF 51ページ）
施工中

定期報告

  1. 対象規模を確認盛土・切土は高さや面積、土石の堆積は高さと面積により判定。
  2. 許可日から3か月ごとに報告前回報告から3か月以内。休止中も許可日から完了日まで必要。
  3. 報告書と現況写真を提出宅地造成・特定盛土等は細則第12号、土石の堆積は細則第13号様式。
  4. 対策を求められた場合は対応報告結果に応じて必要な対策を講じる。
原資料：印刷48～49ページ（PDF 52～53ページ）
施工中

中間検査

  1. 対象か確認定期報告を要する規模で、排水施設の設置など「特定工程」を含む宅地造成・特定盛土等が対象。土石の堆積は対象外。
  2. 特定工程終了から4日以内に申請省令第13号様式、平面図、施工写真を提出。工区を分けた場合は工区ごと。
  3. 県の検査を受ける必要な是正があれば、是正・再検査。
  4. 合格証を受けて次工程へ排水施設の周囲を埋めるなどの次工程は、合格証の交付後に行う。
原資料：印刷49～51ページ（PDF 53～55ページ）
完了

宅地造成・特定盛土等の完了検査

工事完了から4日以内に省令第9号様式で申請します。県が許可内容・技術基準への適合を確認し、問題がなければ検査済証を交付します。工区を分けた場合は工区ごとに申請します。

原資料：印刷52～56ページ（PDF 56～60ページ）
完了

土石の堆積の除却確認

堆積した土石を全て除却した後、工事完了から4日以内に省令第11号様式で確認申請をします。位置図・平面図・工事写真などを添付します。県が除却を確認し、問題がなければ確認済証を交付します。

原資料：印刷52～56ページ（PDF 56～60ページ）
関連申請

適合証明書の交付申請

建築確認で盛土規制法に適合することを証する書面が必要な場合、適合証明書の交付を申請できます。原資料は細則第15号様式、正副2部、手数料の納付を示しています。

原資料：印刷56ページ（PDF 60ページ）

6. 通常届出後の手続き

届出後

変更・廃止・完了

計画変更

変更後の工事に着手する30日前までに変更届を提出します。特定盛土等は省令第21号、土石の堆積は省令第22号様式です。変更後に許可対象規模となる場合は、許可申請へ切り替えます。

工事の廃止

届出対象規模未満で廃止する場合、細則第11号様式の廃止届と現況写真を提出します。届出対象規模を超えている場合は、変更届出を行い、災害防止措置を講じて工事を完了させる流れです。

工事の完了

工事完了後、速やかに細則第14号様式の完了届と、完了後の状況写真を提出します。

原資料：印刷62～64ページ（PDF 66～68ページ）

7. その他の届出

通常の許可・届出とは別に、原資料第7章には三つの入口が設けられています。

経過措置

区域指定時に進行中だった工事

  1. 指定日時点で施工中か確認原資料の指定日は令和7年4月1日。一定規模の宅地造成・特定盛土等・土石の堆積が対象。
  2. 指定日から21日以内に届出原資料の提出期間は令和7年4月1日～22日。宅地造成・特定盛土等は省令様式第15、土石の堆積は第16。
  3. 県が届出情報を公表対象規模によって図面等を添付。
  4. 計画変更時は変更届細則第10号様式。変更後に許可対象規模となる場合は許可申請。
  5. 完了後は速やかに完了届と写真細則第14号様式を提出。

この指定時の提出期間は原資料に記載された過去の経過措置です。現在の案件への適用判断には用いないでください。

原資料：印刷65～68ページ（PDF 69～72ページ）
設備の除却

擁壁・崖面崩壊防止施設・排水施設等の除却

  1. 除却する施設を確認高さ2m超の擁壁・崖面崩壊防止施設、排水施設、地滑り抑止ぐい等の全部または一部の除却が対象。既に許可・通常届出に含まれるものは除外。
  2. 着手14日前までに届出省令様式第17を1部提出。
  3. 変更・廃止があれば届出変更は細則第10号、廃止は細則第11号様式と現況写真。
  4. 完了後は速やかに完了届と写真細則第14号様式を提出。
原資料：印刷68～69ページ（PDF 72～73ページ）
用地転用

公共施設用地から宅地・農地等への転用

  1. 公共施設用地を宅地または農地等に転用既に許可・通常届出に含まれるものは除外。
  2. 転用日から14日以内に届出省令様式第18を1部提出。
原資料：印刷69ページ（PDF 73ページ）

理解度チェック

問いを開いて答えを確認できます。

Q1. 特定盛土等規制区域で、許可規模未満だが届出規模に達する工事は、いつ届け出る？

工事に着手する30日前までです。工事完了後は速やかに完了届と写真を提出します。

Q2. 土石の堆積の許可工事は、完了時に何を申請する？

土石を全て除却した後、除却の確認を申請します。問題がなければ確認済証が交付されます。

Q3. 中間検査の対象となる工程の後、すぐに埋戻しを進めてよい？

いいえ。特定工程終了から4日以内に中間検査を申請し、合格証の交付を受けてから次工程に進みます。

Q4. 届出済みの計画が変更で許可規模に達したら？

変更届だけではなく、許可対象規模の計画となった段階で許可申請を行います。

Q5. 都市計画法の開発許可でみなし許可となれば、施工中の手続きも全て不要？

いいえ。原資料は、標識掲示、対象となる定期報告・中間検査が必要と説明しています。
